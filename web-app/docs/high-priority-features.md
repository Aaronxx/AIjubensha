## 1. 语音房间

### 页面定位
剧本杀游戏结束后或准备阶段的语音复盘/讨论空间，玩家可以通过语音交流，增强社交体验。

### 页面结构
```
语音房间
├── 顶部栏
│   ├── 房间名称（可编辑）
│   ├── 房间号（可复制）
│   └── 关闭按钮
├── 用户列表区（Grid布局）
│   ├── 用户卡片（头像+昵称+麦克风状态）
│   ├── 房主标识（皇冠图标）
│   ├── 说话音量指示器（音频可视化）
│   └── 快捷操作（禁言/踢人-房主权限）
├── 底部功能区
│   ├── 麦克风开关
│   ├── 扬声器开关
│   ├── 语音转文字（可选）
│   └── 离开房间
└── 聊天面板（可收起）
    ├── 语音转文字消息
    └── 快捷表情
```

### 核心功能
| 功能 | 说明 |
|------|------|
| 实时语音 | WebRTC实现低延迟语音通信 |
| 音量可视化 | 说话时显示音量波形 |
| 语音转文字 | 实时转写，方便记录 |
| 背景音乐 | 可选氛围音乐 |
| 房主管理 | 禁言、踢人、转让房主 |

### 按钮/交互
- 🎤 麦克风（开/关）
- 🔊 扬声器（开/关）
- ✏️ 房间名称编辑
- 📋 复制房间号
- 👑 房主标识
- 🚪 离开房间
- 💬 展开/收起聊天

## 2. 回放系统

### 页面定位
完整记录并回放历史对局，支持查看每个时间点的游戏状态、对话内容和投票过程。

### 页面结构
```
回放播放器
├── 顶部控制栏
│   ├── 返回按钮
│   ├── 剧本名称
│   ├── 日期时间
│   └── 分享按钮
├── 播放控制区
│   ├── ⏮️ 快退10秒
│   ├── ⏯️ 播放/暂停
│   ├── ⏭️ 快进10秒
│   ├── ⏱️ 当前时间 / 总时长
│   ├── 🔄 播放速度（0.5x/1x/1.5x/2x）
│   └── 📍 章节标记（可跳转）
├── 主内容区（三栏布局）
│   ├── 左侧：时间线
│   │   ├── 章节标记点
│   │   ├── 关键事件（对话/线索发现/投票）
│   │   └── 可点击跳转
│   ├── 中间：游戏画面
│   │   ├── 群聊界面还原
│   │   ├── 搜证界面还原
│   │   └── 投票界面还原
│   └── 右侧：玩家列表
│       ├── 玩家头像
│       ├── 角色名
│       ├── 身份（游戏结束后显示）
│       └── 当前发言高亮
├── 底部进度条
│   ├── 时间轴（带事件标记）
│   ├── 拖拽跳转
│   └── 章节缩略图
└── 信息面板（可切换）
    ├── 对话记录（可搜索）
    ├── 线索发现时间线
    └── 投票详情
```

### 核心功能
| 功能 | 说明 |
|------|------|
| 完整回放 | 还原整个游戏过程 |
| 时间跳转 | 跳到任意时间点 |
| 章节导航 | 预设关键点（每幕开始/搜证/投票） |
| 多视角切换 | 切换不同玩家的视角 |
| 倍速播放 | 0.5x-2x速度调节 |
| 导出分享 | 导出精彩片段或完整回放 |

### 按钮/交互
- ⏯️ 播放/暂停
- ⏮️ ⏭️ 快进快退
- 📊 播放速度选择
- 🔍 缩放时间轴
- 👁️ 视角切换（玩家选择）
- 🔖 添加书签
- 📤 分享回放
- 💬 显示/隐藏对话面板

│   │   ├── 分类筛选（地点/人物/物品）

│   │   ├── 角色头像
│   │   ├── 角色关系图
│   │   └── 已透露信息
│   └── 时间线概览
├── 主画布区（可缩放/拖拽）
│   ├── 无限画布
│   ├── 卡片系统
│   │   ├── 线索卡片（可拖拽）
│   │   ├── 人物卡片
│   │   ├── 时间卡片
