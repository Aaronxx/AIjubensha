# AI推理叙事游戏 - 完整页面层级结构

## 导航层级总览

```
首页 (Level 1)
├── 入口一：剧本
│   ├── 二级：剧本列表页
│   │   ├── 三级：剧本详情页
│   │   │   ├── 四级：游戏房间（准备大厅）
│   │   │   │   └── 五级：游戏进行页
│   │   │   └── 四级：剧本评价页
│   │   └── 三级：筛选/搜索结果页
│   └── 二级：剧本分类页
│
├── 入口二：排行榜
│   ├── 二级：推理积分榜
│   ├── 二级：社交活跃榜
│   └── 二级：剧本贡献榜
│
├── 入口三：任务
│   ├── 二级：每日任务
│   ├── 二级：成就系统
│   │   └── 三级：成就详情
│   └── 二级：新手引导进度
│
├── 模块：限时活动Banner → 二级：活动详情页
├── 模块：新手引导 → 二级：剧本游玩
├── 模块：全服喊话 → 二级：喊话发布页
├── 模块：热门动态 → 二级：动态详情页
│   └── 三级：用户个人主页
│
└── Tab导航
    ├── Tab: 首页（当前）
    ├── Tab: 剧本 → 剧本列表页
    ├── Tab: 快速组局 → 快速匹配弹窗/页
    ├── Tab: 社交 → 社交广场页
    │   ├── 二级：动态列表
    │   ├── 二级：好友列表
    │   │   └── 三级：私聊页面
    │   └── 二级：关注列表
    └── Tab: 我的 → 个人中心页
        ├── 二级：战绩详情
        ├── 二级：剧本记录
        ├── 二级：收藏夹
        ├── 二级：设置
        │   └── 三级：账号安全/隐私设置
        ├── 二级：商城
        │   ├── 三级：商品详情
        │   └── 三级：订单记录
        └── 二级：钱包/充值
```

## 详细页面结构

### Level 1: 首页 (home-v2.html)

**页面模块：**
| 模块 | 类型 | 说明 |
|------|------|------|
| Banner轮播 | 展示 | 限时活动入口，点击进入活动详情 |
| 三大入口 | 导航 | 剧本/排行榜/任务 |
| 新手引导卡片 | 功能 | 显示进度，点击进入游戏 |
| 全服喊话 | 社交 | 弹幕式展示，点击发表 |
| 热门动态 | 社交 | Feed流，点击进入详情 |
| Tab Bar | 导航 | 5个Tab切换 |

**Tab Bar 按钮：**
- 首页（激活状态，金色）
- 剧本
- 快速组局（中间悬浮橙色按钮）
- 社交
- 我的

### 入口一：剧本 → 二级页面

#### 二级：剧本列表页 (script-selection-final.html)

**页面模块：**
| 模块 | 类型 | 按钮/交互 |
|------|------|----------|
| 搜索区 | 功能 | 搜索输入框、筛选按钮(⋯) |
| 热门推荐Banner | 导航 | 点击进入热门列表 |
| 横向分类卡片 | 导航 | Trending/New/For You 横向滑动 |
| 推荐剧本列表 | 展示 | 剧本卡片，点击进入详情 |
| Tab Bar | 导航 | 同首页 |

**剧本卡片模块：**
- 剧本封面（emoji + 背景）
- 剧本名称
- 标签（本格/推理/社交/悬疑/情感/惊悚）
- 评分（⭐ 9.2）
- 玩过人数

#### 三级：剧本详情页

**页面模块：**
| 模块 | 类型 | 按钮/交互 |
|------|------|----------|
| 剧本封面大图 | 展示 | - |
| 剧本信息 | 展示 | 名称/类型/难度/时长/人数 |
| 剧情简介 | 展示 | 展开/收起 |
| 角色列表 | 展示 | 点击角色查看详情 |
| 评价区 | 社交 | 查看全部评价 |
| 开始游戏按钮 | 主操作 | 大按钮，点击进入房间 |
| 收藏按钮 | 次操作 | ⭐收藏 |
| 分享按钮 | 次操作 | 分享图标 |

#### 四级：游戏房间（准备大厅）

**页面模块：**
| 模块 | 类型 | 按钮/交互 |
|------|------|----------|
| 房间信息 | 展示 | 房间号/剧本名/私密性 |
| 玩家列表 | 展示 | 头像/昵称/准备状态 |
| 房主操作 | 功能 | 踢人/转让房主/设置 |
| 聊天区 | 社交 | 文字输入/发送 |

**房间设置弹窗：**

- 最低人数设置

#### 五级：游戏进行页 (index.html)

**核心游戏界面，包含4个子屏幕：**

**A. 聊天屏幕 (ChatScreen)**
| 模块 | 按钮/交互 |
|------|----------|
| 返回按钮 | ← 返回（确认弹窗） |

| 线索提示 | 💡 提示框 |
| 线索详情弹窗 | 点击查看已发现线索 |

**C. 个人资料屏幕 (ProfileScreen)**
| 模块 | 按钮/交互 |
|------|----------|
| 返回按钮 | ← |

| 统计卡片 | 侦探投票率/凶手逃脱率/总场次 |
| 徽章展示 | 成就徽章 |
| 最近战绩 | 列表展示 |

**D. 商城屏幕 (ShopScreen)**
| 模块 | 按钮/交互 |

## 页面跳转流程示例

### 流程1：开始一局游戏
```
首页 → 剧本入口 → 剧本列表 → 剧本详情 → 游戏房间 → 游戏进行
 (L1)    (L2)       (L3)       (L4)        (L5)
```

### 流程2：查看他人战绩
```
首页 → 热门动态 → 动态详情 → 用户主页 → 战绩详情
 (L1)    (L2)       (L3)       (L4)
```

### 流程3：充值购买
```
首页 → 我的 → 钱包 → 选择档位 → 支付 → 返回
 (L1)  (L2)  (L3)    (L4)
```

### 流程4：完成成就
```
游戏进行 → 结算 → 获得成就弹窗 → 我的 → 成就系统 → 成就详情
  (L5)      (返回)     (弹窗)      (L2)     (L3)
```
